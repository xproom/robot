# ROBOT 셀프 챌린지

6일짜리 **셀프 챌린지 미션 트래커**를 연습용으로 재구현한 **정적 웹앱**입니다.
백엔드 없이 순수 HTML/CSS/JS로 동작하며, 상태는 브라우저 `localStorage`에 저장됩니다.
GitHub Pages로 바로 호스팅할 수 있습니다.

> 참고 챌린지 사이트(셀프 챌린지 미션 트래커 유형)를 분석해, 특정 브랜드/운영
> 콘텐츠를 베끼지 않고 동일한 **기능 구조**만 깨끗하게 다시 구현한 결과물입니다.
> 로그인·운영자 코멘트 등은 실제 인증이 아닌 **클라이언트 데모**입니다.

## 주요 기능

- **접속 화면** — 전화번호 + 접속코드 입장(데모 코드 `ROBOT`), 기기 저장 옵션
- **진행 현황** — D-day, 진행률 바, 완료 개수
- **일차별 미션** — 잠김 / 오늘 / 진행 가능 / 완료 상태 표시 (날짜 기준 잠금 해제)
- **미션 상세** — 목표·결과물, 단계 가이드, 참고 링크
- **미션 인증** — 인증샷 업로드(미리보기), 제출 완료 표시, 운영자 코멘트(데모)
- **미리보기 모드** — 모든 일차를 미리 열어보는 토글
- **마스터 계정** — 전화번호 `010-0000-0000` + 접속코드 `MASTER`로 입장하면 날짜와 관계없이
  모든 일차가 열림 (`data/challenge.json`의 `masterAccount`에서 변경)
- 라이트/다크 테마, 모바일 대응

## 구조

```
.
├── index.html            # 페이지 뼈대 + 헤더/푸터
├── assets/
│   ├── styles.css        # 테마·레이아웃
│   └── app.js            # 라우팅·상태·렌더링 (의존성 없음)
├── data/
│   └── challenge.json    # 미션 데이터(일차/목표/단계/링크)
└── .nojekyll             # GitHub Pages가 파일을 그대로 서빙하도록
```

미션 내용을 바꾸려면 `data/challenge.json`만 수정하면 됩니다.

## 로컬 실행

`fetch`로 JSON을 읽으므로 파일을 직접 여는 대신 간단한 서버로 실행하세요.

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

## GitHub Pages 배포

1. 저장소 **Settings → Pages**
2. **Source**: `Deploy from a branch`
3. **Branch**: `main` / 폴더 `/ (root)` 선택 후 저장
4. 잠시 후 `https://xproom.github.io/robot/` 에서 확인
